BUILD THE APK ONLINE (no Android Studio):
1. Create a free GitHub account and a new repository.
2. Upload ALL files/folders of this project (keep .github/workflows/build.yml).
3. Open the repo > Actions tab > "Build APK" > wait ~3-5 min.
4. Open the finished run > Artifacts > download FAM-apk > unzip > install app-debug.apk.

FIRST RUN: allow notifications and "Don't optimize battery" so alerts keep arriving when the app is closed.
